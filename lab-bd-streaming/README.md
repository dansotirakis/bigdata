# Módulo: Streaming

## Resumo prático

Este módulo deve ser desenvolvido como um exercício de fixação para implementar uma pipeline de dados em tempo real.

### O que precisa ser feito

- definir uma fonte de dados de entrada;
- criar uma estrutura de ingestão e processamento;
- estabelecer um fluxo de saída para armazenamento ou visualização;
- documentar os principais componentes da solução.

### Entregáveis sugeridos

- um esquema de arquitetura simples;
- scripts ou notebooks com o fluxo implementado;
- um README explicando o problema, a solução e os próximos passos.

### Objetivo pedagógico

Praticar a construção de uma solução incremental de streaming, com foco em organização, clareza e entendimento do fluxo de dados.
