# Módulo: Data Quality

## Resumo prático

Este módulo deve ser desenvolvido como um exercício de fixação para trabalhar com qualidade de dados e validação de datasets.

### O que precisa ser feito

- definir um conjunto de dados de referência;
- identificar regras básicas de validação;
- implementar verificações de consistência, completude e formato;
- registrar problemas encontrados e ações corretivas.

### Entregáveis sugeridos

- um notebook ou script com as validações;
- uma lista de regras de qualidade;
- um README com os critérios de sucesso do módulo.

### Objetivo pedagógico

Exercitar a construção de processos de qualidade de dados com foco em confiabilidade, rastreabilidade e análise crítica.
